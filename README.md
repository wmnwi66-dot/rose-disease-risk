# バラ年間旬別 平年気象データ＆5大病害リスク総合診断

緯度・経度を指定し、過去の気象データを
**1月上旬・1月中旬・1月下旬......12月下旬**
の36区分に集計して、バラの主要5病害について気象条件から見た相対的なリスクを診断するWindows向けGUIソフトです。

> **重要:**
> このソフトが表示する「安全0～危険6」は、病害の発生確率や発病を保証するものではありません。過去の気象条件から、病害が発生・進展しやすい条件の強さを相対的に評価したものです。

------------------------------------------------------------------------

## 1. このソフトでできること

緯度・経度を入力して **「年間旬別病害リスクを集計・診断」**
を押すと、指定地点について次の情報を旬別に表示します。

-   平均気温
-   最高気温
-   最低気温
-   平均湿度
-   平均降水量
-   黒点病リスク
-   うどんこ病（露地）リスク
-   うどんこ病（軒下）リスク
-   べと病リスク
-   さび病リスク
-   備考・注意事項

さらに画面上の **「判定基準を見る」**
から、データの取得方法と病害判定の考え方を確認できます。

**「判定数値を変更」**
では、病害ごとの温度・湿度・葉濡れ時間などの閾値を変更できます。

------------------------------------------------------------------------

## 2. 使い方

### 2-1. 起動

Python版を使用する場合は、Python 3で `gsdfaga_disease_adjustable.py`
を実行してください。

必要な外部パッケージは `requests` です。

``` bash
pip install requests
```

TkinterはPythonの標準GUI機能です。Windows向けの通常のPythonインストールでは利用できます。

### 2-2. 緯度・経度を入力

画面上部に、

-   緯度
-   経度

を入力します。

例：

``` text
緯度 35.17
経度 136.9972
```

その後、

**「年間旬別病害リスクを集計・診断」**

を押します。

### 2-3. 結果を見る

取得が完了すると、1月上旬から12月下旬までの36旬が表示されます。

# 3. 気象データはどこから取得しているか

このソフトは **Open-Meteo Historical Weather API** を利用しています。

長期間を比較するため、プログラムでは **ERA5-Land**
を明示的に指定しています。

Open-MeteoのHistorical Weather
APIでは、ERA5-Landは世界規模の再解析データで、約0.1°（約11km）の空間解像度を持ちます。Open-Meteoは、長期間の気候比較ではERA5またはERA5-Landを一貫して使用することを推奨しています。

参考：

-   https://open-meteo.com/en/docs/historical-weather-api

### 3-1. 指定した緯度・経度＝観測所そのもの、ではありません

指定した座標をOpen-Meteoに渡し、APIが採用したデータ格子について、

-   データ地点の緯度
-   データ地点の経度
-   標高
-   タイムゾーン

を取得しています。

そのため、画面の「取得データ・集計条件」には、

**指定座標**

と

**データ取得グリッド中心**

の両方を表示します。

つまり、このソフトは「指定座標に気象観測所がある」という意味ではありません。

------------------------------------------------------------------------

# 4. 何年分のデータを使うのか

このプログラムは実行年を基準に、

**現在年－11年 ～ 現在年－1年**

を対象にします。

たとえば2026年に実行した場合：

``` text
2015～2025年
```

の11年間です。

そのため、画面では「過去11年平均」と表現しています。

> **注意:**
> これは気象庁などでいう正式な「平年値（通常30年）」ではありません。\
> このソフト独自の11年間の平均です。

------------------------------------------------------------------------

# 5. 旬別の集計方法

1か月を次の3つに分けます。

  区分   日付
  ------ ------------
  上旬   1～10日
  中旬   11～20日
  下旬   21日～月末

12か月 × 3区分なので、年間36旬です。

## 5-1. 気温・湿度

各旬について、対象11年間の日別データを集めて平均します。

-   平均気温 → 日平均気温の平均
-   最高気温 → 日最高気温の平均
-   最低気温 → 日最低気温の平均
-   湿度 → 日平均相対湿度の平均

## 5-2. 降水量

各年について、その旬の降水量を合計します。

その後、11年間の各年の旬合計を平均します。

つまり、

``` text
各年の旬降水量
↓
11年分を平均
↓
その旬の平均降水量
```

という計算です。

------------------------------------------------------------------------

# 6. 葉濡れ時間の推定

病害判定では「葉がどれくらい濡れていた可能性があるか」が重要です。

ただし、このソフトには実際の葉濡れセンサーのデータはありません。

そこで時間別気象データから、次の条件を使って **「葉濡れ候補時間」**
を推定しています。

``` text
相対湿度 90%以上
      または
降水量 0.1mm超
```

この条件に該当する時間を1時間としてカウントします。

### 重要

これは**実測葉濡れ時間ではありません**。

樹冠内の葉の向き、風、日射、雨の当たり方、乾燥速度などは個別には測定していないため、

**「気象条件から葉が濡れている可能性が高い時間を推定した値」**

として扱っています。

------------------------------------------------------------------------

# 7. 病害リスクの基本的な考え方

最終表示は、

``` text
安全0
警戒1
危険2
危険3
危険4
危険5
危険6
```

の7段階です。

数字が大きいほど、このソフトが設定した病害好適条件が強いことを意味します。

ただし、

> 危険5 ＝ 発病確率50%

という意味ではありません。

あくまで、このプログラム内部の**相対リスクスコア**です。

計算途中の小数値を最終的に四捨五入し、0～6の範囲に収めて表示します。

------------------------------------------------------------------------

# 8. 黒点病の判定

黒点病では、特に **葉濡れ時間と温度** を重視します。

## 8-1. 温度係数

初期設定では次のようになっています。

  平均気温                    係数
  ------------------------- ------
  18～26℃                     1.00
  14～29℃の範囲で上記以外     0.75
  判定範囲内だが上記以外      0.40
  10℃未満または32℃超             0

## 8-2. 葉濡れ時間の点数

初期設定：

  推定葉濡れ時間/日     点数
  ------------------- ------
  2時間未満                0
  2～4時間未満             1
  4～6時間未満             2
  6～8時間未満             4
  8時間以上                5

基本的には、

``` text
葉濡れ点 × 温度係数
```

で計算します。

さらに、

-   降水量が30mm超
-   葉濡れ4時間/日以上

の場合は最低リスク2を保証します。

また、

-   葉濡れ6時間/日以上
-   平均気温18～27℃

の場合は最低リスク3を保証します。

------------------------------------------------------------------------

# 9. うどんこ病の判定

うどんこ病は、

``` text
温度
×
湿度係数
```

を基本にしています。

さらに、露地と軒下を分けています。

## 9-1. 温度帯

初期設定では、

-   20～27℃：最適温度
-   15～28.5℃：中程度の好適温度
-   10～30℃：低めの好適温度
-   8～31℃：判定対象範囲

として基本点を設定しています。

## 9-2. 湿度

湿度が高いほど係数を大きくします。

露地と軒下では係数が異なります。

## 9-3. 露地と軒下の違い

### 露地

雨によって葉面が洗い流される可能性を考慮し、降水量に応じて減点します。

### 軒下

雨が直接当たりにくいことを想定して、露地のような雨による減点を行いません。

そのため、同じ気温・湿度でも、

**露地と軒下で結果が異なる**

ことがあります。

------------------------------------------------------------------------

# 10. べと病の判定

べと病では、平均気温だけでなく、

-   温度
-   湿度
-   20℃未満の推定葉濡れ時間
-   降水量
-   15～20℃の推定葉濡れ時間
-   30℃超の時間

を組み合わせています。

基本式は概念的には、

``` text
6
×
温度係数
×
湿度係数
×
葉濡れ係数
×
降水係数
```

です。

## 10-1. 15～20℃の葉濡れ

15～20℃の推定葉濡れ時間が少ない場合、過大評価を抑えるために追加補正を行います。

## 10-2. 真夏の高温

30℃超の時間が多い場合は、べと病リスクを下げる補正を行います。

これは、単純に「湿度が高いから真夏もべと病危険」とならないようにするためです。

## 10-3. 最低リスク保証

初期設定では、

-   最適温度15～20℃
-   20℃未満の葉濡れ6時間/日以上
-   湿度75%以上

なら、少なくとも「警戒1」。

さらに、

-   20℃未満の葉濡れ8時間/日以上
-   湿度80%以上

なら、少なくとも「危険2」。

とする補正があります。

------------------------------------------------------------------------

# 11. さび病の判定

さび病は、

``` text
葉濡れ点
×
温度係数
×
湿度係数
```

を基本としています。

初期設定では、

-   最適温度：14～20℃
-   好適温度：10～23℃
-   判定範囲：8～25℃

です。

さらに、

-   降水量30mm超 → 加点
-   14～20℃
-   葉濡れ4時間/日以上
-   湿度80%以上

の条件では、最低リスク2を保証します。

------------------------------------------------------------------------

# 12. 備考・注意事項について

表の「備考・注意事項」は、病害スコアそのものとは別に、気象条件から注意すべき状況を文章で表示します。

例えば、

-   夜露・結露注意
-   朝夕の多湿・露注意
-   高温薬害・夏バテ注意
-   日中の薬害注意
-   高温多湿（べと・黒点警戒）
-   長雨による黒点多発
-   黒点病：葉濡れ推定○時間/日
-   べと病：20℃未満の葉濡れ推定○時間/日
-   乾燥注意（ハダニ等）
-   低温停滞期

などです。

これらは「病害スコアそのもの」ではなく、栽培上の補足情報です。

# 13. 「判定数値を変更」について

画面の **「判定数値を変更」** から、病害判定に使う数値を変更できます。

変更できる項目には、

-   温度の上下限
-   最適温度
-   好適温度
-   湿度の境界
-   葉濡れ時間の境界
-   葉濡れ点
-   降水量の境界
-   温度係数
-   湿度係数
-   葉濡れ係数
-   最低リスク保証
-   高温抑制

などがあります。

設定を保存すると、

``` text
risk_thresholds.json
```

に保存されます。

次回起動時には、この設定が読み込まれます。

> **注意:**
> 数値を変更すると診断結果も変わります。研究資料などを参考に変更する場合は、変更前の設定を記録しておくことをおすすめします。

# 16. このソフトの限界

このソフトは、病害発生を直接観測するシステムではありません。

特に次の点には注意してください。

### 気象データの限界

ERA5-Landは再解析データです。実際の圃場・庭・ベランダに設置した温湿度計や雨量計の値とは異なる場合があります。

### 空間解像度

ERA5-Landは約0.1°（約11km）の格子データです。

同じ市内でも、

-   山
-   谷
-   河川周辺
-   市街地
-   標高差

などによって実際の環境は変わります。

### 葉濡れの限界

葉濡れ時間はセンサーによる実測ではなく、湿度・降水量などから推定しています。

### 病害の限界

実際の発病には、

-   品種
-   樹勢
-   葉の状態
-   剪定
-   通風
-   日照
-   栽培密度
-   灌水方法
-   周辺植物
-   前年からの病原菌量
-   実際の葉濡れ状態

など、多くの要因が影響します。

したがって、本ソフトの結果だけで薬剤散布などの判断を自動的に決定することは想定していません。

------------------------------------------------------------------------

# 17. データ・研究上の位置づけ

このソフトの病害判定は、病害ごとの気象条件に関する知見を参考にしながら、気温・湿度・降水・推定葉濡れ時間を組み合わせた**独自の相対リスクモデル**です。

したがって、

> 「この計算式そのものが農業試験機関の正式な発生予察モデルである」

という意味ではありません。

特に、葉濡れ時間の推定方法や各係数、最低リスク保証などは、このソフトの診断モデルとして設定されています。

------------------------------------------------------------------------

# 18. Open-Meteoについて

気象データ取得にはOpen-Meteo Historical Weather APIを利用しています。

Open-MeteoのHistorical Weather
APIは、過去の気象データとしてERA5、ERA5-Landなどの再解析データを提供しています。

公式ドキュメント：

https://open-meteo.com/en/docs/historical-weather-api

Open-Meteoの説明では、長期間の気候比較ではERA5またはERA5-Landを一貫して利用することが推奨されています。
