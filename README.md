バラ病害リスク診断 v1.0.0
バラの過去11年平均の気象データから、旬別（上旬・中旬・下旬）の病害・ハダニリスクを表示するWindows向けGUIアプリです。
主な機能
過去11年の気象データを旬別に集計
平均気温・最高気温・最低気温・湿度・降水量を表示
黒点病
うどんこ病（露地）
うどんこ病（軒下）
べと病
さび病
ハダニ（露地）
ハダニ（軒下）
0～6の相対リスク表示
「時期・平均気温…」の表ヘッダーを固定
判定数値をGUIから変更・保存可能
気象データ
気温・湿度：ERA5-Land
降水量：ERA5
ハダニ判定について
ハダニは高温・乾燥条件を中心に評価し、降雨による抑制を加味しています。
軒下は露地より降雨の影響を受けにくい想定のため、同じ気象条件ではリスクが高めに出やすくしています。
これは発生確率（％）ではなく、気象条件から見た相対的な環境リスク指数です。
実際の発生には、持ち込み、寄主植物の状態、風通し、日照、天敵なども影響します。
EXEの作成
Windowsで `build_exe.bat` を実行してください。
作成されるファイル：
`dist\RoseDiseaseRisk.exe`
Python版
`rose_disease_risk.py` をPython 3で実行できます。
必要なライブラリ：
`pip install -r requirements.txt`
設定ファイル
アプリで設定を保存すると、実行ファイルと同じフォルダに以下が作成されます。
`config_seasonal.json`
`risk_thresholds.json`
これらはユーザーごとの設定なので、初回公開版では同梱していません。
